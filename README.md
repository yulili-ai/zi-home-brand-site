# 智爱家 · 个人概念作品

这是以「智爱家」为主题制作的单页品牌网站概念作品，**非自如或智爱家官方站点**，不代表品牌方的发布或背书。正式品牌信息请以[智爱家官网](https://zihome.ziroom.com/index)为准。

网站使用原生 HTML、CSS、JavaScript，无构建步骤。双击仓库根目录的 `index.html` 即可预览；动画库通过锁定版本的 HTTPS CDN 加载，图片和字体从本地相对路径加载。

公开页面：[GitHub Pages](https://yulili-ai.github.io/zi-home-brand-site/)

## 素材与使用范围

智爱家、自如的名称与标识，以及页面中的照片、手写字图和文案，归各自权利人所有。它们仅用于展示此个人概念作品；公开仓库不授予他人复制、改编或再分发这些素材的许可。未使用的原始 JPG、二维码及系统文件未上传。

字体 `fonts/LongCang-signoff.woff2` 来源于 [Google Fonts 的 Long Cang](https://github.com/google/fonts/tree/main/ofl/longcang)，遵循 [SIL OFL 1.1](./fonts/OFL-LongCang.txt)。页面引用的 GSAP、ScrollTrigger、Lenis 各遵循其自身许可。
